# Sofabooking Landing Page

Konzept-Landing-Page (Deutsch) für [Sofabooking](https://sofabooking.com): das KI-Buchungssystem der Wunderbyte GmbH, das sich per Chat einrichten lässt.

## Kernbotschaft

**Mach einfache Buchungen zu deinem USP.**
Dein Buchungssystem ist der wichtigste Baustein deiner Kundenreise. Sofabooking passt sich 100% an dein Business an: 30% weniger No-Shows, 20% mehr Umsatz.

## Tech

- Eine einzige `index.html`, keine Dependencies, kein Build-Step
- Fonts über Google Fonts (Sora + Inter)
- Vanilla JS: Scroll-Reveal, animierte Counter, Chat-Demo-Animation, Cursor-Glow auf Feature-Cards
- Voll responsiv (Desktop, Tablet, Mobile)

## Lokal ansehen

Einfach `index.html` im Browser öffnen, oder:

```bash
npx http-server . -p 8788
```

## Deployment

Statisch hostbar überall (GitHub Pages, Netlify, Vercel). Kein Server nötig.
